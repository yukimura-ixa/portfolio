01 — ผลงานเด่น

โปรเจกต์ที่ใช้งานจริง

2566 – ปัจจุบัน

ระบบจัดตารางเรียนตารางสอนสำหรับโรงเรียนมัธยม

เริ่มจากโปรเจกต์จบการศึกษาที่ สจล. ทำร่วมกับเพื่อน แล้วผมพัฒนาต่อหลังเรียนจบจนกลายเป็นระบบที่โรงเรียนใช้จัดตารางจริง ช่วยให้ฝ่ายวิชาการจัดตารางได้เร็วขึ้น ไม่มีครูหรือห้องเรียนถูกจองซ้อนกัน และครูกับนักเรียนเปิดดูตารางผ่านมือถือได้ทุกเวลา

  • ลากแล้ววางคาบเรียนลงตาราง ระบบตรวจทันทีว่าครูหรือห้องเรียนชนกันหรือไม่
  • ล็อกคาบกิจกรรมที่หลายห้องเรียนร่วมกัน (เช่น ชุมนุม เข้าแถว) และคัดลอกตารางจากภาคเรียนก่อนมาแก้ต่อได้
  • ออกตารางครู ตารางนักเรียน และตารางสรุปรวม เป็น Excel และ PDF พร้อมสิทธิ์ผู้ใช้ 3 ระดับ (แอดมิน / ครู / นักเรียน)
  • รองรับโครงสร้างหลักสูตรตามกระทรวงศึกษาธิการ มี E2E test ด้วย Playwright และ CI/CD บน GitHub Actions

Botty — แอปสะสมแต้มรีไซเคิลขวดพลาสติกบน LINE

แอปสำหรับโรงเรียนที่เปิดใช้ได้ในแอป LINE ทันทีโดยไม่ต้องติดตั้งเพิ่ม นักเรียนถ่ายรูปขวดพลาสติกที่นำมาทิ้ง AI จะตรวจว่าเป็นขวดจริง แล้วให้แต้มและเหรียญ แต้มใช้ขึ้นกระดานอันดับ ส่วนเหรียญใช้ซื้อของตกแต่งสวนต้นไม้ของตัวเอง ทำให้การแยกขยะกลายเป็นเกมที่นักเรียนอยากกลับมาเล่นทุกวัน

  • ล็อกอินด้วยบัญชี LINE ผ่าน LIFF แล้วแลกเป็น Firebase custom token
  • ระบบกันโกงหลายชั้น: ตรวจรูปซ้ำ, เว้นระยะ 60 วินาที, จำกัด 20 ครั้งต่อวัน และต้องสแกน QR ของเจ้าหน้าที่ที่เปลี่ยนทุก 30 วินาทีก่อนได้แต้ม
  • ระบบเกม: ระดับต้นไม้ 4 ขั้น, สะสมวันต่อเนื่อง (streak), ร้านค้า, สวนแบบลากวาง และกระดานอันดับระดับห้อง / ชั้น / ทั้งโรงเรียน
  • แดชบอร์ดครูส่งออกข้อมูลไป Google Sheets ได้ การปรับแต้มเกิน ±10 ต้องให้แอดมินอีกคน อนุมัติซ้ำ
